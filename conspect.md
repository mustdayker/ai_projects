## Этап 0 - Шаг 1 - Пункт 6

### Задание
Откройте любой онлайн-токенизатор, например [tiktokenizer.vercel.app](tiktokenizer.vercel.app) (выберите модель `gpt-4o` / `o200k_base`). 

Выполните 4 мини-эксперимента и запишите результаты — это первые записи в вашу базу знаний (`ai_projects/notes/tokens.md`)

1. Русский vs английский. Вставьте одну и ту же фразу на двух языках (например, `«Дата-инженер строит пайплайны данных»` / `«Data engineer builds data pipelines»`). Запишите: сколько токенов у каждой версии, во сколько раз русская дороже.
2. SQL. Вставьте реальный запрос из вашей практики (10–15 строк). Посмотрите, во сколько токенов он превратился и как дробятся идентификаторы и даты.
3. Числа. Вставьте `12893912` и `999999999999999999`. Покажите себе: модель видит не числа, а ошмётки.
4. Форматирование. Вставьте компактный JSON `{"a":1,"b":2}` и тот же JSON с отступами. Сравните счётчики токенов.

### Выполнение
```
1.
Data engineer builds data pipelines - 12 токенов
Дата-инженер строит пайплайны данных - 18 токенов

2.
SELECT id, name FROM table WHERE 1=1 - 18 токенов

3.
12893912 - 10 токенов
999999999999999999 - 13 токенов

4.
{"a":1,"b":2} - 9 токенов
{
"a":1,
"b":2
} - 11 токенов
```

### Практическое правило: 
При прикидках стоимости и контекста русского текста закладывайте +50% к английским оценкам.
