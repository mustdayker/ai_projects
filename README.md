# AI Projects

Репозиторий для изучения всего, что связано с **искусственным интеллектом, агентами и автоматизацией**.

Здесь собраны эксперименты, заметки и проекты по разным направлениям AI — от базовых концепций до практических агентных систем.

## Цели

- Изучить основы и современные подходы в области AI
- Разобраться в устройстве и создании AI-агентов
- Освоить инструменты автоматизации на базе AI
- Накопить практический опыт через мини-проекты и эксперименты

## Направления изучения

| Направление | Что входит |
|-------------|-----------|
| 🤖 AI-ассистенты и LLM | Работа с большими языковыми моделями, промпт-инжиниринг, RAG |
| 🧠 Агенты | Архитектуры агентов, планирование, инструменты, мультиагентные системы |
| ⚙️ Автоматизация | AI-воркфлоу, пайплайны, интеграции, автоматизация рутинных задач |
| 🛠️ Инструменты и фреймворки | LangChain, LangGraph, AutoGen, CrewAI, MCP и другие |
| 📊 Практика | Мини-проекты, прототипы, эксперименты |

## Структура репозитория

```
ai_projects/
├── README.md           # Этот файл
├── notes/              # Заметки и конспекты по изученным темам
├── projects/           # Практические проекты и эксперименты
└── resources/          # Полезные ссылки, статьи, курсы
```

## Как вести обучение

1. **Теория** — конспектирую ключевые темы в `notes/`
2. **Практика** — реализую идеи в виде проектов в `projects/`
3. **Разбор** — фиксирую выводы и полезные ресурсы в `resources/`
