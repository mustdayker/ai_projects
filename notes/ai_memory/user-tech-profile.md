# Технический профиль пользователя

- Уровень: middle Data Engineer; уверенно работает с данными, Python/SQL/Docker — база не нужна.
- Цель обучения AI/агентов: расширить кругозор и продвинуться на работе — автоматизация и более сложные комплексные задачи.
- Особые требования: создание RAG с нуля на локальных моделях; умение работать в закрытых контурах (без облачных API) для применения на работе.

## Оборудование
- Windows PC, 64 GB RAM, Intel Core i5-14600K, GeForce RTX 5060 Ti 16 GB VRAM.
- VRAM 16 GB: локально реально гонять модели ~14B в квантизации Q4–Q6 и ~20B (напр. gpt-oss-20b в MXFP4); 32B — на пределе в сильной квантизации.

## Развёрнутый Docker-стек (можно использовать и расширять в обучении)
- Postgres с векторным расширением (pgvector)
- Spark
- MinIO (S3-совместимое хранилище)
- Jupyter
- Не обязательно использовать всё — это доступные ресурсы.
